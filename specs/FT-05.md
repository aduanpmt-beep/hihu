# FT-05 Form Data Pemesan

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-05), Bagian 8 (AC-03), Bagian 9 (TC-04).

## Tujuan
Pengguna dapat mengisi nama, alamat penjemputan (jika memilih Antar-Jemput), dan catatan khusus sebelum mengirim pesanan.

## Alur
1. Pengguna mengisi kolom Nama Pemesan.
2. Jika opsi Antar-Jemput aktif, kolom Alamat Penjemputan tampil dan wajib diisi.
3. Pengguna dapat menambahkan Catatan Khusus secara opsional.
4. Saat tombol kirim ditekan, spasi awal dan akhir dihapus lalu validasi dijalankan. Jika ada error, pesan muncul di bawah kolom terkait dan fokus berpindah ke kolom error pertama.

## Data
- Tidak memakai data tarif khusus; terhubung ke status `hasDelivery` dari FT-03.

## Aturan dan rumus
- `customerName`: wajib tidak kosong setelah `.trim()`.
- `pickupAddress`: wajib tidak kosong setelah `.trim()` hanya jika `hasDelivery === true`.
- `notes`: opsional; bila kosong setelah `.trim()`, diganti `-` saat masuk template pesan.

## Input dan validasi
- **Nama Pemesan** (`name="customerName"`, `autocomplete="name"`, wajib):
  - Error jika kosong: `Isi nama Anda terlebih dahulu, misalnya Budi Santoso.`
- **Alamat Penjemputan** (`name="pickupAddress"`, `autocomplete="street-address"`, kondisional wajib jika Antar-Jemput aktif):
  - Error jika kosong saat Antar-Jemput aktif: `Isi alamat penjemputan lengkap, misalnya Jl. Mawar No. 12, RT 02.`
- **Catatan Khusus** (`name="notes"`, opsional):
  - Tidak ada syarat wajib.

## Tampilan dan teks
- Judul bagian: `Data Pemesan`
- Setiap input memiliki label yang selalu terlihat dan ukuran teks minimal `16px`.
- Jika Antar-Jemput tidak aktif, kolom alamat disembunyikan dan info singkat menjelaskan pesanan diantar sendiri ke toko.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| TC-04 / AC-03 | Antar-Jemput aktif, Nama `"Budi"`, Alamat `""` | Muncul error pada kolom alamat, fokus pindah ke kolom alamat | PRD TC-04, AC-03 |
| FT05-B1 | Nama hanya berisi spasi `"   "` | Validasi gagal dan menampilkan error pada kolom nama | Tambahan |
